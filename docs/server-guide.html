🔑 1. Sunucuna Bağlanma (Tek Tıkla Bağlan)

Kendi Windows bilgisayarında PowerShell veya Terminali açtığında doğrudan sunucuna bağlanmak için bu komutları kullanırsın:

💻 VPS Yönetim Konsoluna Bağlan (Root/Admin SSH) Ana Bağlantı

Sunucunun Linux komut satırına ana yetkili (kayra) olarak bağlanır. Şifre sormaz, C:\Users\kayra\.ssh\id_rsa anahtarını kullanır.

ssh -i C:\Users\kayra\.ssh\id_rsa kayra@82.153.241.173
💬 ShadowLine Sohbetine Yönetici Olarak Gir Sohbet

Doğrudan Port 2222 üzerinden senin sohbet sunucuna bağlanır ve seni oda yöneticisi (@) yapar.

ssh -i C:\Users\kayra\.ssh\id_rsa kayra@82.153.241.173 -p 2222

⚡ 2. Her Gün Kullanacağın 10 Hayat Kurtarıcı Komut

Sunucuya her girdiğinde kafan karıştığında bu temel komutlarla her şeyi kontrol edebilirsin:

1. Çalışan Portları ve Servisleri Gör (Kim Ne Dinliyor?) Temel

Sunucunda 22, 80, 443, 2222, 6697 portlarının açık ve çalışır olduğunu anında listeler.

sudo ss -tulpn
2. RAM Durumu (Ne Kadar Bellek Kaldı?) İzleme

Kullanılan ve boşta kalan RAM miktarını megabayt cinsinden temiz bir tabloyla gösterir.

free -m
3. Disk Alanı Kontrolü (Harddisk Doldu mu?) İzleme

Diskte ne kadar yer kaldığını GB cinsinden gösterir (Özellikle `/` dizininin doluluk yüzdesine bak).

df -h
4. Canlı Süreç & Görev Yöneticisi (Htop) Canlı

Windows Görev Yöneticisi gibidir. CPU, RAM ve çalışan tüm süreçleri canlı renkli grafiklerle izletir (Çıkmak için: `q`).

htop
5. PM2 Durumu (ShadowLine Çalışıyor mu?) PM2

Node.js sohbet uygulamasının ayakta olup olmadığını, uptime süresini ve harcadığı RAM'i gösterir.

pm2 status

🔄 3. PM2 & Systemd Servis Yönetimi

Sunucunda iki ana uygulama çalışıyor: Portfolyo siten (Systemd) ve ShadowLine Sohbet Servisi (PM2). Bunları nasıl kontrol edeceksin:

ShadowLine Sohbetini Yeniden Başlat (Restart) PM2

Kodları veya ayarları (.env) değiştirdiğinde sunucuyu anında güncel şekilde yeniden başlatır.

pm2 restart whononymous --update-env
Portfolyo Web Siteni Kontrol Et & Yeniden Başlat Systemd

Next.js portfolyonun durumuna bakar veya takılırsa yeniden başlatır.

sudo systemctl restart kayra-portfolio && sudo systemctl status kayra-portfolio
Canlı Hata Loglarını İzle (Kayan Yazı) Loglar

Node.js uygulamasında bir hata olursa terminale anında basar (Durdurmak için: `Ctrl + C`).

pm2 logs whononymous

🌐 4. Nginx Web Sunucusu & SSL Sertifikası

Nginx, dışarıdan gelen HTTPS isteklerini (Port 443) karşılayıp portfolyo sitene aktaran ön kapıdır:

Nginx Ayarlarını Test Et (Sözdizimi Hatası Var mı?) Önemli

Nginx konfigürasyonunu değiştirdiğinde hata yapıp yapmadığını kontrol eder. `syntax is ok` diyorsa güvenlidir.

sudo nginx -t
Nginx'i Kesintisiz Yeniden Yükle (Reload) Nginx

Mevcut bağlantıları koparmadan ayarları günceller.

sudo systemctl reload nginx
SSL Sertifikalarını Otomatik Yenile (Certbot) SSL

Let's Encrypt SSL süresi bitmeye yakınken sertifikaları günceller.

sudo certbot renew --dry-run

💬 5. ShadowLine Özel Yönetim Komutları

Sadece sunucu sahibinin kullanabileceği şifreli log çözme ve yeni kullanıcı yetkilendirme komutları:

Şifreli Konuşmaları ve IP Loglarını Çöz ve Oku Admin

Sunucudaki tüm AES-256-GCM ile şifrelenmiş denetim kayıtlarını otomatik çözüp ekrana basar.

cd /home/kayra/whononymous && npm run logs
Canlı Sohbet Akışını Yönetici Olarak İzle (Live Stream) Canlı

Sohbette anlık kim kime ne mesaj attıysa gerçek zamanlı ekrana basar.

cd /home/kayra/whononymous && npm run logs -- --live
Sohbete Yeni Bir Güvenilir Kullanıcı Ekle (SSH Anahtarı ile) Yetkilendirme

Bir arkadaşının `id_rsa.pub` açık anahtarını `keys/chat-users.json` içine ekleyerek ona doğrudan şifresiz giriş hakkı verebilirsin.

nano /home/kayra/whononymous/keys/chat-users.json

🛡️ 6. Güvenlik, Ban Listesi & Saldırı Önleme

Sunucun Fail2ban ile korunmaktadır. Kötü niyetli IP'leri ve durumları buradan kontrol edebilirsin:

Fail2ban Hangi IP'leri Banlamış? (Saldırgan Listesi) Güvenlik

SSH portuna izinsiz girmeye çalışıp engellenen IP'leri listeler.

sudo fail2ban-client status sshd
Yanlışlıkla Banlanan Bir Arkadaşının Banını Kaldır (Unban) Unban

Arkadaşın şifreyi üst üste yanlış girip banlandıysa banını tek tıkla açar:

sudo fail2ban-client set sshd unbanip IP_ADRESI

🚨 7. "Sunucu Çöktü / Yanıt Vermiyor, Ne Yapacağım?"

Herhangi bir gün sitene veya sohbete ulaşılamadığında panik yapmadan sırasıyla şu 3 adımı uygula:

Adım 1: Nginx ve Node Servislerini Tek Seferde Yeniden Başlat Acil

Sorunların %95'i kilitlenen süreçlerden kaynaklanır. Bu tek satır tüm web ve sohbet servislerini baştan başlatır:

sudo systemctl restart nginx && sudo systemctl restart kayra-portfolio && pm2 restart all
Adım 2: Disk Dolmuş mu Kontrol Et ve Temizle Acil

Disk %100 dolarsa Linux kilitlenir. Eski gereksiz paketleri ve sistem loglarını temizler:

sudo apt-get autoremove -y && sudo apt-get clean && sudo journalctl --vacuum-time=3d
Adım 3: Son Çare Sunucuyu Temizce Yeniden Başlat (Reboot) Son Çare

Tüm donanım ve çekirdeği yeniden başlatır. 30-40 saniye sonra her şey otomatik ayağa kalkar.

sudo reboot
